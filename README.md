# МиниГОСТ

Упрощенная учебная реализация алгоритма блочного шифрования на основе российского стандарта ГОСТ 28147-89 (Магма).

## Описание

**МиниГОСТ** — это упрощенная версия блочного шифра ГОСТ 28147-89, предназначенная для образовательных целей. Алгоритм демонстрирует основные принципы работы блочных шифров с сетью Фейстеля, используя уменьшенные размеры блоков и ключей для простоты понимания и анализа.

### Основные характеристики

- **Размер блока**: 16 бит (2 байта)
- **Размер ключа**: 64 бита (8 байт)
- **Количество раундов**: 12
- **Структура**: Сеть Фейстеля
- **Режимы работы**: ECB (Electronic Codebook)

⚠️ **Внимание**: Это учебная реализация. Не используйте ее для защиты реальных данных в продакшн-системах.

## Использование

### API библиотеки

#### Шифрование одного блока

```c
#include "minigost.h"

uint16_t plaintext = 0x1234;
uint8_t key[8] = {0x00, 0x11, 0x22, 0x33, 0x44, 0x55, 0x66, 0x77};

// Шифрование
uint16_t ciphertext = minigost_encrypt_block(plaintext, key);

// Расшифрование
uint16_t decrypted = minigost_decrypt_block(ciphertext, key);
```

#### Шифрование массива данных (ECB режим)

```c
#include "minigost.h"

// Данные должны быть кратны 2 байтам
uint8_t plaintext[] = {0x01, 0x23, 0x45, 0x67, 0x89, 0xAB, 0xCD, 0xEF};
uint8_t ciphertext[8];
uint8_t decrypted[8];
uint8_t key[8] = {0x00, 0x11, 0x22, 0x33, 0x44, 0x55, 0x66, 0x77};

// Шифрование
int result = minigost_encrypt_ecb(plaintext, ciphertext, 8, key);

// Расшифрование
result = minigost_decrypt_ecb(ciphertext, decrypted, 8, key);
```

### Компиляция вашей программы

#### Использование статической библиотеки

```bash

make lib/libminigost.a

# Скомпилируйте вашу программу
```

#### Использование shared библиотеки

```bash
# Соберите shared библиотеку
make lib/libminigost.so  # или .dylib на macOS

# Скомпилируйте программу
gcc -O3 -Iinclude -o my_program my_program.c -Llib -lminigost

# Запуск (указать путь к библиотеке)
LD_LIBRARY_PATH=./lib ./my_program  # Linux
DYLD_LIBRARY_PATH=./lib ./my_program  # macOS
```

### Python-обертка

```python
from minigost_python import MiniGost

# Создать экземпляр шифратора
cipher = MiniGost()

# Установить ключ
key = [0x12, 0x34, 0x56, 0x78, 0x9A, 0xBC, 0xDE, 0xF0]
cipher.set_key(key)

# Зашифровать блок
plaintext = 0x1234
ciphertext = cipher.encrypt_block(plaintext)

# Расшифровать блок
decrypted = cipher.decrypt_block(ciphertext)

# Зашифровать массив данных
data = b"Hello, MiniGOST!"
encrypted = cipher.encrypt_ecb(data)
decrypted_data = cipher.decrypt_ecb(encrypted)
```

## Производительность

Алгоритм оптимизирован для максимальной скорости:

- **Предвычисленные таблицы**: Функция подстановки выполняется за O(1)
- **Inline функции**: Минимизация накладных расходов на вызовы функций
- **Битовые операции**: Все преобразования используют быстрые побитовые операции
- **Компиляция с `-O3 -march=native`**: Максимальная оптимизация компилятора

Типичная производительность на современном процессоре:
- **Шифрование одного блока**: ~10-20 наносекунд
- **Пропускная способность**: несколько ГБ/с для больших объемов данных

Запустите `make benchmark` для тестирования на вашей системе.

## Сравнение с ГОСТ 28147-89 (Магма)

| Параметр | МиниГОСТ | ГОСТ 28147-89 |
|----------|----------|---------------|
| Размер блока | 16 бит | 64 бита |
| Размер ключа | 64 бита | 256 бит |
| Количество раундов | 12 | 32 |
| Размер S-box | 4→4 бита | 4→4 бита |
| Структура | Сеть Фейстеля | Сеть Фейстеля |

МиниГОСТ сохраняет ключевые принципы оригинального алгоритма, но использует уменьшенные размеры для упрощения анализа и обучения.

## Криптоанализ

### Линейная характеристика δπ

Реализован инструментарий для вычисления линейной характеристики (максимального преобладания) с использованием Fast Walsh-Hadamard Transform:

```bash
# Быстрый тест (~0.05 сек)
gcc -O3 -march=native -I. -o build/test_delta_pi tools/test_delta_pi.c -lm
./build/test_delta_pi

# Полное вычисление (~6 сек)
./run_delta_pi.sh

# Batch-анализ для N случайных ключей
./batch_compute_delta_pi.sh 100
```

- δπ = 0.0240478516

## Безопасность

⚠️ **ВАЖНО: Ограничения безопасности**

МиниГОСТ — это **учебный проект**. Он не предназначен для защиты реальных данных по следующим причинам:

1. **Малый размер блока** (16 бит) — уязвим к атакам перебором
2. **Упрощенные S-box** — могут иметь криптографические слабости
3. **Режим ECB** — не обеспечивает семантическую безопасность
4. **Малое количество раундов** — может быть недостаточно для стойкости

Для реальной защиты данных используйте проверенные алгоритмы:
- AES (Advanced Encryption Standard)
- GOST 28147-89 (полная версия)
- ChaCha20
- И другие стандартизованные алгоритмы
