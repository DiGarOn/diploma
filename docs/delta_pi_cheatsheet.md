# Шпаргалка: Вычисление δπ для МиниГОСТ

## Команды

### 1. Быстрый тест (~0.05 сек)
```bash
gcc -O3 -march=native -I. -o build/test_delta_pi tools/test_delta_pi.c -lm
./build/test_delta_pi
```
**Выводит:** Оценка δπ, α, β для первых 256 масок

### 2. Полное вычисление (~6 сек)
```bash
./run_delta_pi.sh
```
**Создаёт:**
- `results/delta_pi_result.txt` — детальный отчёт
- `verify_in_sage.py` — скрипт проверки

### 3. Batch-анализ (статистика по множеству ключей)
```bash
# 10 случайных ключей (~1 минута)
./batch_compute_delta_pi.sh 10

# 100 ключей (~10 минут)
./batch_compute_delta_pi.sh 100
```
**Создаёт:** CSV + автоматический статистический анализ

### 4. Проверка в SageMath
```bash
sage verify_in_sage.py                # Быстрая проверка
sage verify_in_sage.py --full-check   # Полная проверка (долго!)
```

## Интерпретация

**Сравнение с эталонами:**
- AES S-box: δπ ≈ 0.0156 (1/64)
- ГОСТ «Кузнечик»: δπ ≈ 0.0078 (1/128)
- **МиниГОСТ: δπ = 0.0240** (1/41.6)

**Вывод:** Хуже, чем у AES и Кузнечика, но приемлемо для учебного 16-битного шифра.

## Что такое δπ?

**Линейная характеристика δπ** — максимальное преобладание (корреляция) между линейными соотношениями на входе и выходе шифра.

**Шкала стойкости:**
- δπ → 0: Идеальная стойкость
- δπ < 0.02: Отличная стойкость
- δπ < 0.05: Хорошая стойкость
- δπ > 0.1: Плохая стойкость
