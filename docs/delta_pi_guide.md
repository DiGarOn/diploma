# Вычисление линейной характеристики δπ для МиниГОСТ

## Описание

Программа вычисляет линейную характеристику δπ (дельта пи) для алгоритма МиниГОСТ по методике из работы Шишулина Д.И. (ВКР, СКБ 2020-2026, стр. 34-36).

### Что такое δπ?

**Линейная характеристика δπ** — метрика, показывающая максимальную корреляцию между линейными комбинациями входных и выходных битов шифра. Определяет стойкость к линейному криптоанализу:

- **δπ → 0**: Отличная стойкость (идеал)
- **δπ < 0.02**: Хорошая стойкость (AES: ~0.0156)
- **δπ < 0.05**: Приемлемая стойкость
- **δπ > 0.1**: Слабая стойкость, уязвим к атакам

## Алгоритм

Для каждой маски β ≠ 0:

1. Строим булеву функцию g^β(x) = ⊕(βᵢ · yᵢ), где y = π(x)
2. Создаём вектор t длины N: t[x] = {-1, +1} (биполярное представление)
3. Применяем Fast Walsh-Hadamard Transform для коэффициентов Фурье
4. Нормируем коэффициенты делением на N
5. Вычисляем корреляции c(α,β) для всех α ≠ 0
6. Находим максимум |c(α,β)|

Итоговая характеристика: **δπ = max_{α,β≠0} |c(α,β)|**

```bash
# Компиляция тестовой версии

# Запуск теста (проверяет первые 256 масок β, ~1 секунда)
```

## Проверка в SageMath

Для верификации корректности вычислений:

```bash
sage verify_in_sage.py
```

**Что делает:**
1. Загружает lookup-таблицу из C header
2. Пересчитывает корреляцию c(α, β) вручную:
   - Для каждого x: проверяет α·x ⊕ β·π(x)
   - Подсчитывает корреляцию: (count_0 - count_1) / N
3. Сравнивает с результатом C программы

**Ожидаемый результат:**
```
✓ УСПЕХ: Вычисления совпадают!
  Корреляция c(α, β) подтверждена.
Разница: < 1e-7
```

## Интерпретация результатов

### Для МиниГОСТ с ключом 0xDEADBEEFCAFEBABE:

**Полный результат:** δπ = 0.0240478516

**Линейное соотношение:**
- α = 0xCE65 (маска входа)
- β = 0x59A0 (маска выхода)
- Вероятность p ≈ 0.512 (отклонение 1.2% от случайного)

**Сравнение с эталонами:**
- AES S-box: δπ ≈ 0.0156 (1/64)
- ГОСТ «Кузнечик»: δπ ≈ 0.0078 (1/128)
- МиниГОСТ: δπ = 0.0240 (1/41.6)

**Вывод:** МиниГОСТ имеет приемлемую, но не идеальную линейную характеристику. Она выше, чем у AES и Кузнечика, что ожидаемо для учебного 16-битного шифра с упрощённой структурой.

## Оптимизация

Текущая реализация использует:

- ✅ **-O3**: Максимальная оптимизация компилятора
- ✅ **-march=native**: Использование всех инструкций CPU (AVX, SSE)
- ✅ **Lookup-таблица**: O(1) шифрование вместо O(n) раундов
- ✅ **FWT**: Быстрое преобразование Уолша O(N log N)
- ✅ **Inline функции**: Минимизация накладных расходов
- ✅ **`__builtin_parity`**: Аппаратная инструкция подсчёта четности

**Результат:** ~11 миллиардов операций/секунду

### Возможные дальнейшие оптимизации:

1. **OpenMP** — параллелизация по маскам β (ускорение в 4-8x на многоядерном CPU)
2. **SIMD** — векторизация FWT и parity (ускорение в 2-4x)
3. **CUDA/GPU** — вычисление на GPU (ускорение в 100-1000x, как в оригинальной работе)

### Булева функция g^β:
```
g^β(x) = β₁·y₁ ⊕ β₂·y₂ ⊕ ... ⊕ β₁₆·y₁₆
где y = π(x) — выход шифра
```

### Корреляция c(α,β):
```
c(α,β) = (1/N) · Σ_{x∈V_n} (-1)^(α·x ⊕ β·π(x))
```

### Линейная характеристика:
```
δπ = max_{α,β≠0} |c(α,β)|
```
