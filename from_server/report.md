## 4. Наблюдения по распределению средних ложных delta

По файлу `false_delta_distribution.csv` можно проверять гипотезы о распределении.
На что имеет смысл смотреть в первую очередь:

- насколько среднее близко к нулю относительно стандартного отклонения;
- насколько близки доли положительных и отрицательных значений;
- как меняется `stddev` при переходе от `adaptive_m10` к `adaptive_m100` и `full_material`;
- есть ли выраженная асимметрия по `skewness` и тяжелые хвосты по `excess kurtosis`.
